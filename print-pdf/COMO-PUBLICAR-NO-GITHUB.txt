================================================================================
  COMO PUBLICAR O FLASHPDF NO GITHUB
================================================================================

Download manual: os .exe ficam na pasta release/ do repositorio.


--------------------------------------------------------------------------------
1. PRE-REQUISITOS
--------------------------------------------------------------------------------

  - Conta no GitHub: https://github.com
  - Git instalado no Windows: https://git-scm.com/download/win
  - PowerShell (ja vem no Windows)


--------------------------------------------------------------------------------
2. GERAR OS EXECUTAVEIS
--------------------------------------------------------------------------------

    cd "F:\Documentos\Portifólio\print-pdf\FlashPDF"
    powershell -ExecutionPolicy Bypass -File .\scripts\publish-release.ps1

  Arquivos gerados:

    release\FlashPDF_Portable.exe   (recomendado)
    release\FlashPDF.exe


--------------------------------------------------------------------------------
3. CRIAR O REPOSITORIO NO GITHUB
--------------------------------------------------------------------------------

  1. Acesse https://github.com/new
  2. Nome sugerido: print-pdf
  3. NAO marque "Add a README"
  4. Clique em "Create repository"


--------------------------------------------------------------------------------
4. PRIMEIRO ENVIO
--------------------------------------------------------------------------------

    cd "F:\Documentos\Portifólio\print-pdf"
    git init
    git branch -M main
    git remote add origin https://github.com/RatyelAlves/print-pdf.git
    git add .
    git commit -m "FlashPDF - impressao em lote de PDFs"
    git push -u origin main


--------------------------------------------------------------------------------
5. COMO OS USUARIOS BAIXAM
--------------------------------------------------------------------------------

  Opcao A - Pela pagina do GitHub:
    Repositorio > pasta release > FlashPDF_Portable.exe > Download

  Opcao B - Link direto:

    https://github.com/RatyelAlves/print-pdf/raw/main/release/FlashPDF_Portable.exe


--------------------------------------------------------------------------------
6. ATUALIZAR O PROGRAMA NO GITHUB
--------------------------------------------------------------------------------

  1. Faca alteracoes no codigo (se necessario)
  2. Gere os .exe:

       cd FlashPDF
       powershell -ExecutionPolicy Bypass -File .\scripts\publish-release.ps1

  3. Envie:

       cd ..
       git add .
       git commit -m "Atualiza executaveis"
       git push origin main


--------------------------------------------------------------------------------
7. AUTENTICACAO NO GIT
--------------------------------------------------------------------------------

  Use GitHub CLI (gh auth login) ou Personal Access Token como senha.
  Mais info: https://docs.github.com/en/authentication

  FIM
